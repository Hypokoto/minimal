# Product Definition: Minimal Hyprland Desktop

## 1. Intent
This is an Arch Linux dotfiles repository for a Hyprland-based Wayland desktop environment.
It aims to be a **coherent, intentional, high-end minimal interface** rather than a generic "AI SaaS" aesthetic or an over-decorated rice. The desktop should feel like a premium, professionally engineered OS environment, akin to MacOS but built on Linux and highly keyboard-driven.

## 2. Core Constraints
- **Color Palette:** Strictly locked to `palette.md` and `hypr/colors.lua`. No new colors can be added.
- **Environment:** Hyprland (Wayland), Rofi (Wayland), Waybar, Kitty, Starship.
- **Target Audience:** The creator/owner, needing a distraction-free, lightning-fast workspace with premium visual feedback.

## 3. Surface & Use Case (Operate Mode)
The primary mode is **Operate**. The user is completing tasks (coding, browsing, window management). Scanability, consistency, native expectations, and actual usage speed completely outrank pure expression. Brand lives in the precise details of spacing, layout, typography, and motion.
